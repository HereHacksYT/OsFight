# ⚡ OsFight

3D tabanlı, arkadaş ekleyip sohbet edebileceğin basit bir dövüş oyunu.

## Özellikler
- İsim girme ve localStorage ile hatırlama
- Three.js 3D sahne
- Karakter seçimi (renk değiştirir)
- Arkadaş ekleme ve yerel sohbet
- Geçmişi temizleme

## Deploy
Render üzerinde **Static Site** olarak yayınlayabilirsiniz.
